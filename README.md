# DRSDT+ Battery

Dual-Retrieval Self-Deception Task Plus Battery (DRSDT+) is a modular behavioural experimentation framework for studying:

- self-deception
- motivated memory distortion
- semantic false memory
- delayed honest retrieval
- social-evaluative cognition

---

## Project Goals

The project is designed as:

- an open-source scientific software framework
- a reproducible behavioural experimentation platform
- a modular multilingual research system

Long-term goals include:

- multilingual stimulus architecture
- configurable task pipelines
- behavioural data logging
- open scientific reproducibility
- cross-linguistic experimentation support

## Repository Structure

```text
drsdt_plus-battery/

├── core/
├── tasks/
├── stimuli/
│   └── english_india/
├── data/
└── docs/
```

### Folder Overview

| Folder | Purpose |
|---|---|
| `core/` | Runtime logic and shared utilities |
| `tasks/` | Experimental task modules |
| `stimuli/` | Language-specific stimuli |
| `data/` | Behavioural outputs and logs |
| `docs/` | Documentation and schemas |
